# PRO-CHISTKA Cleaning Control

Локальный Telegram-бот для контроля выездных уборок.

Текущий PoC умеет:
- работать только с владельцем;
- создавать тестовый заказ;
- фиксировать прибытие и геолокацию;
- спрашивать согласие клиента на фото/видео;
- при согласии требовать минимум 4 фото ДО и 4 ПОСЛЕ;
- при отказе не требовать фото;
- фиксировать начало и окончание уборки;
- сохранять фото/видео в приватный Telegram-канал;
- хранить состояние в SQLite;
- открывать маршрут через Яндекс Карты, 2ГИС или Google Maps.

## Запуск
1. Скопировать `.env.example` в `.env`.
2. Вставить `BOT_TOKEN`.
3. Запустить `START_BOT.bat`.
4. Первый пользователь, отправивший `/start`, становится владельцем.
5. Добавить бота администратором приватного архивного канала.
6. Отправить в канал `#bind_archive` — бот сохранит ID канала.

Дальше подключаются Google Calendar, Google Drive backup, напоминания и Mini App.
