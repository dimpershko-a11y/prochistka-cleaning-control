# PRO-CHISTKA Cleaning Control

Локальный Telegram-бот для контроля клининговых объектов.

Сейчас работает:
- владелец + локальная SQLite-база;
- Google Calendar `dim.pershko@gmail.com` как источник объектов;
- автосинхронизация календаря каждые 5 минут;
- ручная кнопка `Обновить календарь`;
- ручное добавление объекта;
- прибытие и геолокация;
- подтверждение согласия клиента на фото/видео;
- минимум 4 фото ДО и 4 ПОСЛЕ при согласии;
- начало и завершение уборки;
- фото/видео в приватном Telegram-канале;
- маршруты через карты;
- русские статусы и время в формате ЧЧ:ММ.

Из Google Calendar импортируются события, в названии которых есть `клининг` или `уборка`.
Адрес берётся из поля Location. Изменение события обновляет объект. Удаление будущего события отменяет объект.

## Запуск
Основной файл: `START_BOT.bat`.
На рабочем столе также есть `PRO-CHISTKA Control Bot.bat`.

Секретный iCal-адрес календаря хранится только в локальном `.env` и не попадает в GitHub.
